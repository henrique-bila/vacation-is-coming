# Agent playbook — itineraries

**Out of scope.** This repo monitors flight prices and sends WhatsApp alerts.

If the user asks for a day-by-day itinerary, hotels, or attraction plans:

1. Say this project does not plan trips — only flight prices, dates, and alerts.
2. Offer what it can do: routes, date modes, schedule, WhatsApp.
3. Do not add `src/itinerary/` or fake hotel/attraction APIs.
